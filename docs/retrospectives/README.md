# Retrospectives

A neutral place to look back on completed work — a milestone, a campaign iteration, a review cycle, or the project as a whole. Retrospectives are historical evidence (Level 3): useful to explain *why* something is the way it is, not something to load by default.

## Questions to Ask

- What worked well?
- What was confusing?
- What took longer than expected?
- What should be improved?
- What did we learn?
- Should anything be promoted into `/kaisys/learning`?
- Should anything change the `/kaisys/playbook`?
- What should be done differently in the next project or milestone?

## What Happens to the Answers

The retrospective document itself stays here, unchanged, as a historical record. Its most useful lessons should be distilled and promoted into `/kaisys/playbook` (if it's about how to work) or `/kaisys/learning` (if it's durable knowledge) — not left to be rediscovered by re-reading old retrospectives.
